# Changelog

All notable changes to this fork are tracked via **GitHub Releases**, generated
automatically from [Conventional Commits](https://www.conventionalcommits.org/)
(`feat:`, `fix:`, …) by `.github/workflows/fork-release.yml` on every
`v*-fork.*` tag.

- Latest releases: <https://github.com/lampame/scrob/releases>
- Upstream releases (synced daily): <https://github.com/ellite/scrob/releases>

Do not edit release history by hand — add a `feat:`/`fix:` commit and let the
release workflow generate the notes. See `AGENTS.md` (CI/CD) and
`README.md` (Contributing) for the commit convention.
